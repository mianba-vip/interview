# 公开范围与历史说明

本公开版用于阅读架构和代码风格，不用于部署完整业务。

## 已撤除的内容

- 学习规划、课程生成、练习生成、追问、判分、推荐、调度等核心实现。
- 模型提示词、Agent / 图工作流、知识锻造和模型适配实现。
- 原数据库结构、迁移与初始化数据、内部测试与业务样例数据。
- 生产配置、部署和运维脚本、监控配置、个人路径、源站地址和凭据。
- 旧桌面工程、打包脚本、站点工程与构建缓存。

以上范围也从可写分支和旧版本标签的历史中裁剪；仅保留经审查的通用代码历史。
Git 作者与日期作为贡献署名保留，提交正文中的部署信息另行脱敏。

GitHub 的历史 PR 引用、缓存和第三方已有副本不随普通历史重写消失，
这些遗留访问需要维护者另行处理，不能据此承诺已经收回全部旧副本。
